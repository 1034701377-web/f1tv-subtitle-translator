# F1 TV 中文字幕 · F1TV Chinese Subtitles

为 F1 TV 添加简体中文字幕：翻译官方解说字幕，也可识别 Track FX 中的车队无线电（TR）与采访。译文按节目时间显示，暂停和回看时仍与节目位置对应。

Chinese subtitles for F1 TV / F1TV: translate official commentary captions and transcribe Track FX team radio and interviews.

**0.10.0 已整合为纯 Chrome 扩展，尚未在扩展商店发布。** 使用自己的 API 密钥，由浏览器直接连接翻译及语音识别服务；无需篡改猴、Node.js、本机服务或配对码。

## 安装测试版

需要 **Chrome 116 或更新版本，以及能在官网正常播放目标节目的 F1 TV 账号**。翻译和语音识别使用你自己的 API 额度。

1. 已有源码构建目录时，打开 Chrome 的“管理扩展程序”，开启“开发者模式”，选择“加载已解压的扩展程序”，加载本项目的 `dist/chrome-extension`。
2. 如果取得发布资产 `F1TV-ZH-Chrome-v0.10.0.zip`，先完整解压到固定文件夹，再加载其中直接包含 `manifest.json` 的目录。GitHub 自动生成的 `Source code (zip)` 是源码，需要开发者构建后才能安装。
3. 打开扩展的设置页，填写自己的翻译 API 并保存；默认使用 DeepSeek。**仅使用官方解说中文字幕时，不必配置 TR。**
4. 刷新 F1 TV 播放页，选择英语解说并开启 **English 字幕**，再打开“中文字幕”。直播可预留约 50 秒处理时间。

设置保存在此 Chrome 用户配置中的扩展本地存储，不使用浏览器同步。保存成功仅表示本地设置已保存，不等于远端 API 请求成功。

## TR / 采访字幕

在扩展设置中配置 Qwen ASR 的 API 密钥，以及与密钥所属地域、业务空间匹配的完整 WebSocket 地址。默认模型为 `qwen-audio-3.1-asr-flash-streaming`。识别结果再由翻译服务翻译，保留原有赛车术语和上下文提示。

- **普通录播**：开启“TR / 采访”后，默认尝试在观看页直接读取独立 Track FX 音轨，不必另开采集页。能否读取取决于该节目音轨及加密情况。
- **直播**：从观看页打开声音采集页，在采集页准备 Track FX 并播放，再点击扩展图标，明确开启“采集声音”。观看页保留英语解说，并落后采集页约 50 秒。
- **没有直播时**：可使用录播页折叠的“用录播测试 TR”工具检验双页链路。录播模拟不能替代真实直播验证。

采集开始后，采集页不外放声音。关闭字幕、收起页面控制台或关闭扩展弹窗，都不会停止采集；结束观看时，明确关闭“采集声音”，采集页恢复声音。关闭采集只停止后续采集，不能撤回已经发送给服务商的数据。

## 从 0.9.x 迁移

先关闭旧扩展的采集开关、停止旧本机服务，在篡改猴中停用并删除本项目旧脚本，再切换到新版扩展。在新版设置页展开“从旧版迁移”，选择原 `.env`，点击“保存设置”并允许连接原服务，即可沿用 API 密钥、接口与模型。文件只在浏览器本地读取；确认成功后可删除旧 `.env`。只保留一份扩展，并刷新所有 F1 TV 页面；不要把密钥文件复制到扩展目录。

后续测试版更新时，结束采集、更新扩展文件，在 Chrome 扩展管理页重新加载，再刷新 F1 TV 页面。当前尚无商店自动更新渠道。

## 使用边界

- 50 秒是处理余量，不是每句字幕的固定延时；不保证每句都能及时完成。识别、翻译可能出错。
- 字幕及必要上下文发送给配置的翻译服务；启用 TR 后，相关音频和识别提示发送给语音识别服务。API 费用和服务商的数据处理规则由你选择的服务与账号设置决定。
- 本地测试、录播和双页模拟的结果不能证明真实直播的时钟、网络与长期采集稳定性。
