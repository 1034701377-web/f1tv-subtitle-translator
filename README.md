# F1 TV 中文字幕系统 · F1TV Chinese Subtitles

为 F1 TV 添加简体中文字幕：翻译官方解说字幕，也可识别 Track FX 中的车队无线电（TR）与采访。译文按节目时间显示，观看页暂停、回看时仍与节目位置对应。

Chinese subtitles for F1 TV / F1TV: translate official commentary captions and transcribe Track FX team radio (TR) and interviews.

## Windows 快速开始

准备 **Windows 10/11 64 位、Chrome 116 或更新版本、篡改猴，以及能正常播放目标节目的 F1 TV 账号**。翻译模型和可选的语音识别服务使用你自己的 API 额度。

1. 点击上方下载链接，或在 Releases 的 **Assets** 下载 `F1TV-ZH-Windows-x64-v0.9.2.zip`。便携包内置运行时，无需安装 Node.js，也无需执行 npm；GitHub 自动生成的 `Source code (zip)` 是源码包。
2. 将整个 ZIP 解压到一个固定文件夹，双击 `start-service.cmd`。观看期间保持服务窗口打开；首页未自动打开时，访问 **http://127.0.0.1:3847/**。
3. 在首页保存**翻译模型的 API** 配置。默认是 DeepSeek；仅用官方解说中文字幕时，不需要配置 TR 声音识别。
4. 在首页点击“安装 / 更新字幕脚本”，由篡改猴完成安装。刷新 F1 TV 播放页，在中文字幕控制台点击“配对本机服务”，粘贴首页复制的配对码。**配对码不是 AI 模型 API 密钥。**
5. 在官网选择英语解说并开启 **English 字幕**，再打开“中文字幕”。直播可点“预留 50 秒翻译时间”，等待解说中文准备就绪后观看。

详细步骤、更新方法和常见问题见 [Windows 使用说明](docs/Windows使用说明.md)。

## 加上 TR / 采访字幕

TR 使用两套服务：**Qwen ASR 识别声音 → DeepSeek 翻译文字**。普通解说字幕直接交给翻译服务。

1. 在本机首页开启“TR 声音识别”，填写自己的百炼 API 密钥，以及对应地域、业务空间的完整 WebSocket 地址。默认识别模型是 `qwen-audio-3.1-asr-flash-streaming`。
2. 在 Chrome“管理扩展程序”开启开发者模式，选择“加载已解压的扩展程序”，加载解压目录中的 `dist/chrome-extension`。扩展在“配对设置”中粘贴同一个本机配对码。
3. 直播时，在观看页打开“TR / 采访”，点击“打开声音采集页”。在新页点“准备 Track FX 并播放”，再点击扩展图标，打开面板中的“采集声音”。**点击图标只展开面板，不会直接采集。**
4. 采集页持续播放，观看页落后约 50 秒，给识别和翻译留出时间。观看页保留英语解说；采集开启时，采集页不外放声音。

关闭字幕、最小化控制台或关闭扩展面板，都不会停止采集。结束观看时，先在扩展中关闭“采集声音”，再关闭本机服务。关闭采集后，采集页恢复声音。

## 没有直播时

普通录播会尝试在观看页直接读取独立 Track FX 音轨，不必另开采集页；能否读取取决于节目音轨及加密情况。

录播观看页保留可选的 **“用录播测试 TR”** 工具，默认折叠。音轨无法直接读取时，或想测试直播使用的采集链路时，可用双页录播检验声音采集、识别、翻译与字幕传送；详见 [录播测试步骤](docs/Windows使用说明.md#用录播测试-tr)。它不能替代真实直播验证。

## 更新与使用边界

- 解压后尽量不移动文件夹：Chrome 加载的扩展依赖这个路径。首次从旧版迁移，先停旧服务，只启用一份字幕脚本，再从新目录的 `dist/chrome-extension` 加载扩展。
- 重启服务后重新复制配对码；已保存的 API 配置保留。浏览器重启后，采集扩展也需重新配对。
- 50 秒是处理余量，不是字幕固定延时，也不保证每句都能及时完成。识别和翻译会有错误，多语种效果取决于所用模型。
- 密钥保存在本机 `.env`，不写入脚本。字幕文字会发送给配置的翻译服务；开启 TR 后，所采集音频还会发送给语音识别服务。详见 [安全说明](SECURITY.md)。
