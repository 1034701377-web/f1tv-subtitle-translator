# F1 TV 字幕翻译脚本

把 F1 TV 官方英文解说字幕提前翻译成简体中文，按照你正在观看的时间显示。支持直播与带英文字幕的回放，可调整字号、字体、透明度和字幕位置。

## 使用前

- 提前安装篡改猴（Tampermonkey）。
- 拥有能在 F1 TV 官网打开直播的会员，并正常登录。
- 安装 [Node.js](https://nodejs.org/) 22.16 或更高版本。
- 准备自己的翻译 API 密钥与余额。默认配置为 DeepSeek；也可用兼容 Chat Completions 的接口。

## 第一次使用

1. [下载项目 ZIP](https://github.com/1034701377-web/f1tv-subtitle-translator/archive/refs/heads/main.zip)，解压到一个固定文件夹。
2. Windows 双击 `start-service.cmd`。浏览器会打开[本机配置页](http://127.0.0.1:3847/)，观看期间保持服务窗口打开。macOS / Linux 在项目文件夹运行 `node server.mjs --open` 即可，无需安装 npm 依赖。
3. 在配置页粘贴**自己的 API 密钥**，点击「保存配置」。默认接口和模型已填好；使用其他服务时展开「其他模型或接口」，修改完整接口地址、模型名称，并将思考参数设为「不发送」。
4. 点击「安装 / 更新脚本」，在篡改猴中确认安装。
5. 点击「复制配对码」。打开或刷新 F1 TV 播放页，在翻译控制台点「配对本机服务」并粘贴。
6. 官网开启 **English 字幕**，点击「开启翻译」。直播可先暂停，点击「预留 50 秒翻译时间」，等待「准备就绪」后播放。

「准备就绪」表示观看位置前方已有至少 **45 秒连续就绪余量**，包括确认过的无字幕时段。暂停时准备够了会等待；播放后继续准备。译文未及时到达时保留英文，不会拦住播放。50 秒是起始建议，可按自己的网络和模型响应手动调整观看位置。

## 之后每次观看

启动 `start-service.cmd` → 复制配对码 → 在 F1 TV 重新配对 → 开启翻译。API 配置和字幕样式只需保存一次；服务重启会更换配对码。

## 密钥与数据

API 密钥只保存在本机 `.env` 中，脚本不含密钥；仓库中的 `.env.example` 密钥为空，`.env` 已被 Git 忽略。翻译时会将当前字幕及少量上下文发送到你配置的 API 服务商。请勿把自己的 `.env` 或配对码公开分享。

默认模型为 `deepseek-flash`，关闭思考模式；接口格式见 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)。保存配置只做格式检查，不自动发送付费测试请求。

## 遇到问题

| 现象 | 处理 |
| --- | --- |
| 未找到英文轨 | 在官网选择 English 字幕；该节目需要有官方英文字幕轨。 |
| 配对失效 / 无法连接 | 保持服务窗口打开，刷新配置页并复制新配对码。 |
| API 认证失败 / 限流 | 检查自己的密钥、余额和接口；修正后关闭再开启翻译。 |
| 中文来不及出现 | 让观看位置再落后一点，暂停等待准备；不要一直追在直播最前沿。 |
| 端口 3847 被占用 | 关闭旧版翻译服务，再启动本项目。 |

使用官网播放器的全屏按钮。画中画与单独视频全屏无法承载本脚本字幕层，会恢复官方字幕。

当前公开版翻译**官方解说字幕**，不含独立 Track FX 音频识别或 TR 翻译，不需要共享标签页。官方没有提供字幕的片段无法由此补译。字幕接口与节目覆盖会随官网变化；本项目与 Formula 1 / F1 TV 无隶属关系。

## 修改源码

运行 `npm run build` 重新生成 `dist/f1tv-zh.user.js`；`npm test` 运行离线的字幕时间轴与分段解析检查。已包含可直接安装的脚本，一般使用无需构建。
