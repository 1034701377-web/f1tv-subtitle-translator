配对使用

同一个配对码，分别粘贴到脚本和扩展。

  1. 保存配置，复制下方配对码。
  2. 刷新 F1 TV 播放页，在中文字幕控制台中配对本机服务，开启中文字幕。
  3. 需要 TR 时，打开采集扩展的「配对设置」，粘贴同一个配对码并保存。

请先保存有效的服务配置。

修改 API 配置后，已有配对仍然有效。重启本机服务后，请重新复制配对码完成配对。

使用方法观看页、采集页如何配合

普通字幕：在 F1 TV 官网开启 English 字幕，再打开中文字幕。观看期间保持本机服务运行。

TR / 采访：从观看页控制台打开采集页，在采集页准备 Track FX 并播放，再打开扩展的「采集声音」开关。采集开启时该标签页静音，关闭后恢复声音。

预留翻译时间：直播时让观看页落后采集页约 50 秒。采集页持续播放，观看页可暂停等待；两页播放同一节目。字幕仍按官方节目时间显示，50 秒用于等待识别和翻译。

回放模拟：在脚本中启用回放模式，让采集页先播放约 50 秒，再播放观看页。关闭扩展面板不会停止采集；结束时关闭「采集声音」。
