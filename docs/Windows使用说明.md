# Windows 使用说明

本文适用于 `F1TV-ZH-Windows-x64-v0.9.2.zip` 便携包。从[项目 Releases](https://github.com/1034701377-web/f1tv-subtitle-translator/releases/tag/v0.9.2)的 Assets 下载。不要把 `Source code (zip)` 当作便携包。

## 1. 解压并启动

需要 Windows 10/11 64 位、Chrome 116 或更新版本、篡改猴，以及能在官网正常播放节目的 F1 TV 账号。便携包已带 Node.js 运行时和所需依赖，不用另装 Node.js/npm。

将整个 ZIP 解压到你准备长期保留的文件夹，再双击其中的 `start-service.cmd`。不要在压缩包预览窗口里运行，也不要只复制启动文件。出现本机服务窗口后，保持它打开；首页地址是 **http://127.0.0.1:3847/**。

使用采集扩展后不要随意移动或删除这个文件夹，因为 Chrome 会从其中的 `dist/chrome-extension` 读取扩展。

## 2. 配置两种服务

在本机首页“配置服务”中设置：

| 用途 | 要填什么 | 什么时候需要 |
| --- | --- | --- |
| 字幕翻译 | 翻译模型 API 密钥；默认 DeepSeek、`deepseek-flash`、关闭思考 | 始终需要 |
| TR 声音识别 | 百炼 API 密钥、对应工作空间的完整 WebSocket 地址；默认 `qwen-audio-3.1-asr-flash-streaming` | 需要 TR / 采访时才开启 |

DeepSeek 默认接口为 `https://api.deepseek.com/chat/completions`。其他兼容接口可在“模型与接口设置”中填写自己的地址和模型。百炼的识别地址必须与 API 密钥的地域、工作空间匹配；复制服务商提供的完整 `wss://` 地址，不凭示例猜写。

点“保存配置”。已保存的密钥不会显示出来，留空表示继续使用原值；关闭 TR 不会删除已保存的语音识别配置。配置保存在当前文件夹的 `.env` 中。显示“已保存”表示本机保存成功，不等于远端模型已经完成一次识别或翻译。

仅翻译官方解说字幕时，跳过 TR 配置和采集扩展即可。

## 3. 安装和配对

先在 Chrome 安装篡改猴。在本机首页点击“安装 / 更新字幕脚本”，确认安装后刷新 F1 TV 播放页。

复制本机首页的配对码，在官网中文字幕控制台点击“配对本机服务”并粘贴。这里用的是**本机配对码，不是 AI 模型 API 密钥**；API 密钥只填在本机配置首页。

需要 TR 时，再安装声音采集扩展：

1. 打开 Chrome 的“管理扩展程序”，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择解压文件夹中的 `dist/chrome-extension`。首页的“复制目录”可帮助定位。
3. 点击采集扩展的“配对设置”，粘贴同一个本机配对码并保存。保存不会自动开始采集。

服务每次启动都会产生新的配对码。重启服务后，脚本和采集扩展都要重新配对；API 密钥不必重填。仅重启浏览器时，采集扩展保存的会话配对也会失效。

## 4. 观看官方解说中文字幕

在 F1 TV 官网选择英语解说，并开启 **English 字幕**，然后打开中文字幕控制台的“中文字幕”。可以折叠“字幕样式”调整字体、字号和透明度，也可以拖动字幕位置。

直播可点击“预留 50 秒翻译时间”，将观看位置调到直播后方约 50 秒。这个按钮只在点击时调整观看位置，会保留当时的播放或暂停状态，不会给每条字幕强行增加 50 秒延时。可以先暂停，等“解说中文已就绪”后继续播放。

## 5. 增加 TR / 采访字幕

直播时，两页打开同一场节目：观看页听英语解说，采集页播放 Track FX。

1. 在观看页开启“TR / 采访”，点击“打开声音采集页”。
2. 在新开的采集页点“准备 Track FX 并播放”。确认该页正常播放，准备时会听到声音。
3. 点击 Chrome 里的采集扩展图标，再打开弹窗内的“采集声音”开关。采集页此时不外放声音；面板显示音轨、已收到音频、送去识别的段数及中文缓存。
4. 让采集页持续播放，观看页保持落后约 50 秒。等待识别和翻译结果后，字幕按官方节目时间出现在观看页。

观看页暂停、关闭 TR 字幕或收起控制台，不会停止采集。关闭弹窗也不会停止采集。结束时在扩展内关闭“采集声音”，采集页恢复声音，再关闭服务窗口。

普通录播会尝试在观看页直接读取独立 Track FX 音轨，开启“TR / 采访”即可；不必另开采集页。加密或不可解码的音轨无法这样读取，可改用下面的录播测试模式。

## 用录播测试 TR

没有直播时，可在**录播观看页**展开“用录播测试 TR”，再启用其中的测试模式。切换会刷新当前页；直播页不显示这个工具。

开启中文字幕后，从观看页打开同一节目的采集页。在采集页定位起点，准备 Track FX 并打开扩展采集；观看页先暂停，让采集页领先约 50 秒后再播放。两页仍按同一节目时间对应。

这是可选的链路检查：能观察扩展有没有收到声音、识别与翻译是否返回、观看页能否收到字幕。它不证明直播中的时钟、网络和长期采集也一定稳定。

## 从旧版迁移或更新

1. 结束当前观看，关闭旧扩展的采集开关，再关闭旧本机服务。只启动一份服务。
2. 解压新版并保留自己的 `.env`。若换了目录，可在旧服务停止后，将自己的 `.env` 复制到新版根目录；不要上传或分享它。
3. 从新目录双击 `start-service.cmd`，在首页安装新版字幕脚本。检查篡改猴，只启用一份本项目脚本；旧“实验骨架”脚本应关闭。
4. 如果扩展目录改变，移除旧采集扩展，再从新版 `dist/chrome-extension` 加载。目录不变时，在 Chrome 扩展管理页重新加载该扩展。
5. 刷新 F1 TV 页面，重新复制本机配对码，完成脚本和扩展配对。

扩展重新加载后，已经打开的 F1 TV 页面需要刷新才能重新连接。把更新安排在不观看时即可，不必在一场正常进行的直播中升级。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 首页打不开 | 服务窗口是否仍在运行；是否已经有旧服务占用本机端口。 |
| 官网没有中文字幕控制台 | 篡改猴和字幕脚本是否启用，安装后是否刷新了官网页。 |
| 普通字幕一直等待 | 官网是否启用了 English 字幕，以及当前节目是否提供该字幕。 |
| 提示重新配对 | 服务或浏览器是否刚重启；从当前首页重新复制配对码。 |
| 扩展不能开始采集 | 是否在本场采集页，是否已准备 Track FX 并正常播放；按面板显示的原因处理。 |
| TR 暂时没有中文 | 音频是否持续增加、是否有真实人声、TR 识别配置是否保存，以及观看页是否预留了时间。静音片段没有字幕是正常情况。 |
| 扩展更新后断开 | 刷新 F1 TV 页面，再检查配对状态。 |

如仍有问题，反馈系统版本、Chrome 版本、直播或录播、页面角色以及界面提示即可。不要附 API 密钥、配对码或完整 `.env`。
