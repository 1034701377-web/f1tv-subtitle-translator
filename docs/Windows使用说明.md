# Windows 使用说明

本文适用于 **0.10.0 纯 Chrome 扩展测试版**，要求 Chrome 116 或更新版本，以及能够播放目标节目的 F1 TV 账号。当前尚未上架扩展商店。使用自己的翻译/语音识别 API 额度，无需安装 Node.js、篡改猴或启动本机服务。

## 1. 安装

在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”：

- 从源码构建后，选择本项目 `dist/chrome-extension`。
- 如果取得 `F1TV-ZH-Chrome-v0.10.0.zip`，完整解压到固定目录，再选择直接包含 `manifest.json` 的解压目录。不要选择 ZIP 文件本身，也不要加载源码根目录。

GitHub 的 `Source code (zip)` 不是已构建扩展资产。测试版加载后不要移动或删除扩展目录。Chrome 加载成功后，可在工具栏固定扩展图标。

## 2. 首次设置

从扩展弹窗进入设置，或在 Chrome 的扩展“详细信息”中打开“扩展程序选项”。设置页是扩展内的 `options.html`。

| 功能 | 设置 | 是否必需 |
| --- | --- | --- |
| 字幕翻译 | 自己的翻译 API 密钥，默认 DeepSeek；需要时调整模型和接口 | 必需 |
| TR / 采访识别 | 自己的百炼 API 密钥、对应地域和业务空间的完整 `wss://` 地址 | 仅使用 TR 时需要 |

默认翻译接口是 `https://api.deepseek.com/chat/completions`；默认语音模型是 `qwen-audio-3.1-asr-flash-streaming`。自定义接口必须是可信的 HTTPS / WSS 地址。百炼地址要从自己对应的服务配置取得，不能仅凭示例猜写。

保存设置后再开始使用。配置保存在当前 Chrome 用户配置中的扩展本地存储，不会浏览器同步；API 请求直接发往相应服务商。**“已保存”只代表本地设置保存成功。** 修改识别配置前先停止当前采集。

## 3. 官方解说中文字幕

1. 刷新 F1 TV 播放页，在官方播放器选择英语解说，并开启 **English 字幕**。
2. 在页面控制台打开“中文字幕”。需要时调整字幕样式和位置。
3. 直播可点击“预留 50 秒翻译时间”，或自行暂停等待翻译。它只调整观看位置，50 秒是处理余量，不是每条字幕的固定延时。

字幕依照节目时间显示。暂停和回看时，以观看页的节目位置为准，不以模型响应的到达时间为准。

## 4. TR / 采访字幕

先在设置页配置 Qwen ASR。普通录播开启“TR / 采访”后，默认尝试在观看页直接读取独立 Track FX 音轨，不必另开采集页；若音轨加密、无法读取或无法解码，可尝试双页录播测试模式。

直播使用两页：观看页保留英语解说，采集页播放 Track FX。

1. 在观看页打开“TR / 采访”，再打开声音采集页。
2. 在采集页准备 Track FX 并播放，确认节目正常播放。
3. 在采集页点击扩展图标，明确开启“采集声音”。采集开始后，该页不外放声音。
4. 让采集页继续播放，观看页落后约 50 秒，等待识别和翻译结果。

打开扩展图标或保存设置不会自动开始采集。关闭字幕、收起页面控制台、关闭扩展弹窗也不会停止采集。结束观看时，在扩展内关闭“采集声音”；采集页恢复声音。已发送给服务商的请求不能通过停止按钮撤回。

## 用录播测试 TR

在录播观看页展开“用录播测试 TR”，启用其中的测试模式；切换会刷新当前页。打开同一节目的采集页，准备 Track FX 并开启采集，让采集页领先观看页约 50 秒后观看。

它可检查双页音频、识别、翻译及字幕传送；真实直播中的时钟、网络和长期采集稳定性仍需单独验证。

## 从 0.9.x 迁移

1. 结束观看，在旧扩展中关闭“采集声音”，然后停止旧本机服务。
2. 在篡改猴中禁用本项目旧字幕脚本；不必为迁移卸载整个篡改猴。
3. 移除或禁用旧采集扩展，再加载一份 0.10.0 新扩展。
4. 在新扩展设置页展开“从旧版迁移”，选择原 `.env`，然后点击“保存设置”并允许连接原服务。密钥、接口和模型会沿用；文件只在浏览器本地读取，不上传。也可以手动填写 API 配置。
5. 刷新所有 F1 TV 页面，只使用新版扩展。

确认配置保存且翻译连接成功后，可以删除旧 `.env`。不要把密钥文件复制到扩展目录，不要在仍正常观看直播时迁移。

## 更新测试版

停止采集后，将新版扩展解压到固定位置；若目录不变，在 `chrome://extensions` 点击该扩展的重新加载，再刷新 F1 TV 页面。若换了目录，先移除旧扩展，再从新目录加载；移除扩展可能清除配置，需要重新填写。

当前尚无商店自动更新渠道。将来商店版的安装和更新说明应以实际发布版本为准。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 官网没有中文字幕控制台 | 新扩展是否启用、加载目录是否正确、安装后是否刷新页面；是否仍启用了旧脚本。 |
| 普通字幕一直等待 | 官网是否开启 English 字幕，节目是否提供该字幕；翻译配置及服务额度是否可用。 |
| 保存成功却不能翻译 | 保存只验证本地配置；查看实际请求的错误提示，检查地址、密钥、模型及额度。 |
| 扩展不能开始采集 | 是否位于本场采集页，Track FX 是否已经准备且播放；按扩展提示处理。 |
| TR 暂时没有中文 | 是否有真实人声、采集是否开启、ASR 配置是否与地域/工作空间匹配，以及观看页是否预留处理时间。 |
| 录播直接读取音轨失败 | 该节目可能没有可用独立音轨或存在加密限制；可尝试双页录播测试。 |
| 更新后页面断开 | 重新加载扩展后刷新 F1 TV 页面。 |

反馈时提供 Chrome 版本、直播或录播、页面角色及错误提示即可。不要附 API 密钥、完整配置、认证资源地址或 `.env`。数据处理说明见 [安全说明](../SECURITY.md)。
