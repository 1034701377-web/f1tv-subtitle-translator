# 扩展商店发布准备

本文是 0.10.0 的提交准备材料，**不表示已经注册、付费、提交审核或上架**。当前测试版从 `dist/chrome-extension` 加载；扩展 ZIP 为 `F1TV-ZH-Chrome-v0.10.0.zip`。真实直播稳定性未验证时，不在文案中承诺直播效果。

## 可用商店文案

**名称建议**：F1 TV 中文字幕助手（非官方）

**简短说明**：为 F1 TV 官方解说及 Track FX 车队无线电提供简体中文字幕，使用你自己的翻译与语音识别 API。

**详细说明**：

> 在 F1 TV 播放页显示按节目时间对应的简体中文字幕，支持官方英语字幕翻译，以及 Track FX 中车队无线电和采访的语音识别与翻译。
>
> 需要能够观看目标节目的 F1 TV 账号，并自行提供翻译服务 API 密钥；TR / 采访识别还需要 Qwen ASR 配置。API 调用可能产生服务商费用。浏览器直接连接用户配置的服务，无需安装本机服务或篡改猴。
>
> 普通录播默认尝试直接读取独立 Track FX 音轨；直播和可选录播模拟使用双页采集，必须由用户明确开启。采集和字幕显示独立，关闭字幕或弹窗不会停止采集。识别和翻译可能有误，需预留处理时间；音轨可用性、节目权限及网络情况会影响结果。
>
> API 密钥只保存在扩展本地存储，不通过浏览器同步。字幕及必要上下文发送给配置的翻译服务；启用 TR 后，相关音频、识别配置和可选提示发送给 Qwen ASR，识别文字再交给翻译服务。详情见本扩展隐私政策。
>
> 本项目为非官方工具，与 Formula 1 / F1 TV 无隶属关系，不提供节目访问权限。

**单一用途**：在 F1 TV 播放页，将官方解说字幕以及 Track FX 的车队无线电和采访内容转换为按节目时间显示的简体中文字幕。

**远程代码声明**：扩展的可执行代码随安装包分发；远程接口仅处理音频/文本并返回识别与翻译数据，不用于下载或执行远程代码。填写前确认最终构建与此一致。

## 权限理由

只填写最终 manifest 实际申请的项目；未使用的权限应从 manifest 移除，不能为将来功能预留。

| 权限或范围 | 提交理由 |
| --- | --- |
| `activeTab` | 用户点击扩展并启动采集时，仅对当时选择的 F1 TV 采集标签页操作。 |
| `tabCapture` | 用户明确开启后采集 Track FX 页的标签页声音，用于 TR / 采访识别。 |
| `offscreen` | 在扩展弹窗关闭后，继续通过隐藏扩展文档处理已授权的音频采集和识别会话。 |
| `storage` | 本地保存 API 配置及扩展设置；密钥存储只向可信扩展上下文开放，不使用 sync。 |
| `declarativeNetRequestWithHostAccess` | 为浏览器直连 Qwen WebSocket 添加认证请求头；会话规则仅限本扩展 initiator 及已配置的确切 endpoint，不拦截无关网页。 |
| `https://f1tv.formula1.com/*` | 读取本节目字幕、播放位置和音轨信息，并在官方播放页显示中文字幕。 |
| 可选主机权限 `https://*/*`、`wss://*/*` | 支持用户填写不同翻译 / ASR 服务地址。保存设置时只申请当前配置 API 的确切 origin；HTTPS 翻译和 WSS 识别分别授权。可选通配声明不是安装时读取所有网站的授权。 |

固定主机权限仅为 F1 TV；不申请 `scripting`、`debugger` 或 `webRequest`。页面脚本只匹配 F1 TV 主框架。CSP 的 `connect-src https: wss:` 用于兼容用户配置的服务，实际访问仍受已授予的主机权限及 Qwen 精确 URL 认证规则约束。

接口数据请求不属于下载远程可执行代码，但仍受用户数据和最小权限规则约束。[MV3 要求](https://developer.chrome.com/docs/webstore/program-policies/mv3-requirements) · [隐私字段](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)

## 隐私与审核复现

- 将 `docs/privacy.html` 托管为无需登录即可访问的 HTTPS 页面，再把真实 URL 填入商店隐私字段；目前仓库文件尚不等于已公开托管。
- 数据声明须与最终实现及隐私页面一致，覆盖 API 认证信息、字幕/转写/音频及实际读取的播放上下文；不能仅因没有开发者服务器就宣称“不处理数据”。不勾选实际未采集的数据类型。
- 首次设置和采集入口应展示数据去向，明确采集开始与停止；新功能若改变数据处理，需要同步更新披露。
- 在审核专用 Test instructions 中说明 F1 TV 订阅、自备 API 额度、English 字幕、录播直读及双页采集的操作和限制。需要提供审核凭据时，使用专用且可撤销的测试凭据，只放审核专用字段，不放代码、公开文案或 ZIP。[测试说明字段](https://developer.chrome.com/docs/webstore/cws-dashboard-test-instructions)

## 尚需完成的发布步骤

- [ ] 完成 Google 开发者账号注册、联系邮箱验证和两步验证；一次性费用以实际注册支付页面为准。[注册](https://developer.chrome.com/docs/webstore/register/) · [账号设置](https://developer.chrome.com/docs/webstore/set-up-account)
- [ ] 如实申报 Trader / Non-Trader；个人开发者不自动等于 Non-Trader，需要时完成身份资料验证。[Trader FAQ](https://developer.chrome.com/docs/webstore/program-policies/trader-verification-faq)
- [ ] 准备不冒充官方的 128×128 PNG 图标、440×280 宣传图及至少一张真实扩展体验截图（建议 1280×800），不含密钥或个人账号信息。[素材要求](https://developer.chrome.com/docs/webstore/images)
- [ ] 公开托管隐私政策，填好支持入口、类别、语言、单一用途、权限理由、数据声明和审核说明。
- [ ] 构建并运行 `node scripts/package-extension.mjs`，确认扩展 ZIP 能按安装说明使用；准确列明实际验证过的场景。
- [ ] 由账号持有人上传 ZIP、选择发布范围并提交审核；可选择审核后再手动发布。通常数天，也可能数周，不能承诺批准时间。[发布](https://developer.chrome.com/docs/webstore/publish) · [审核流程](https://developer.chrome.com/docs/webstore/review-process)
- [ ] 上架成功后再把 README 改为真实商店安装链接；以后提高版本号、上传完整 ZIP 并重新审核，由 Chrome 分发更新。[更新](https://developer.chrome.com/docs/webstore/update)

F1 名称、宣传图和截图仍应遵守第三方商标及版权要求，“非官方”说明不等于取得品牌或节目素材授权。[商店知识产权规则](https://developer.chrome.com/docs/webstore/program-policies/impersonation-and-intellectual-property)
