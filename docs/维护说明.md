# 开发与维护

0.10.1 的用户入口是纯 MV3 扩展，尚未上架扩展商店。安装和旧版迁移见 [Windows 使用说明](Windows使用说明.md)。当前源码只维护扩展；旧本机服务、油猴脚本及演示台可在 Git 历史中查阅。

## 构建与安装

开发环境需要 Node.js 22 或更新版本，无需安装第三方运行依赖。在项目根目录执行：

```text
npm run build
```

随后在 Chrome 116+ 的扩展管理页加载 `dist/chrome-extension`，进入扩展设置页配置自己的 API，再刷新 F1 TV 页面。不直接编辑 `dist/` 构建产物。

| 位置 | 用途 |
| --- | --- |
| `src/` | 页面字幕控制、播放器适配和节目时间逻辑 |
| `extension/` | MV3 扩展入口、设置、采集与浏览器服务调用 |
| `lib/` | 翻译请求、提示词和赛车术语 |
| `scripts/` | 构建、发布打包和源码检查 |
| `tests/` | 自动测试，模拟数据源集中在 `fixtures/` |
| `docs/` | 使用说明、隐私政策与商店发布资料 |
| `dist/chrome-extension/` | 可加载、可打包的完整扩展 |
| `release/` | 本机生成的扩展 ZIP，不提交源码仓库 |
| `local/` | 本机资料，不参与构建或发布 |

版本以 `package.json` 为准；本次目标版本是 0.10.1。源码、扩展 manifest 和构建产物的版本必须一致。普通用户只安装扩展，不运行开发命令。

## 必须保持的行为

- 官方字幕 → 翻译 → 字幕缓存 → 按节目时间显示。
- 录播 TR 默认读取独立 Track FX 音轨；直播或双页录播模拟使用用户明确开启的标签页声音采集。
- TR 音频 → Qwen ASR → 翻译 → 按节目时间传送和显示；保留翻译提示词、ASR 原文与既有时钟/去重保护。
- 采集与字幕显示独立。关闭字幕不停止采集，API 响应时间不能代替节目时间，50 秒只是观看预留量。
- API 密钥保存于 `chrome.storage.local`，限制为 `TRUSTED_CONTEXTS`，不使用 sync，不传给网页。浏览器直接连接用户选定的服务。
- Qwen 鉴权规则仅为会话规则，绑定本扩展 initiator 与确切 endpoint；不申请 `debugger`、`webRequest`，不扩大到无关网站。
- 原生 WebSocket 放在 offscreen 文档，后台通过内部端口控制；Chromium 的 service worker WebSocket 不经过 DNR 鉴权拦截。WSS 接口必须获得自身 WSS origin 权限，不能用 HTTPS 授权替代。
- 扩展可执行逻辑和依赖随包发布，不远程加载脚本或执行远程返回的代码。

## 验证

按变更范围完成最低充分检查：

```text
npm run build
npm run check
npm test
```

局部变更先运行相关检查；纯文档修改不触发模型 API。浏览器直连、真实 F1 TV 采集和真实直播验证必须区分记录，不把录播、模拟、构建成功或安装成功称为直播通过。

更新扩展后在 Chrome 管理页重新加载，再刷新 F1 TV 页面；安排在采集和观看结束之后。

## 纯扩展发布包

构建完成后，在 Windows 开发环境执行：

```text
node scripts/package-extension.mjs
```

该脚本不联网、不安装依赖、不构建，也不启动服务。它只从 `dist/chrome-extension` 的明确文件白名单和根目录 `LICENSE` 复制内容，使用系统 PowerShell 打包。ZIP 根目录直接包含 `manifest.json`，供手动解压安装或商店提交。

输出 `release/F1TV-ZH-Chrome-v0.10.1.zip`。新增运行文件时更新打包清单；密钥、个人资料与开发依赖不入包，临时目录用完清理。

Release 只附扩展 ZIP，说明用户可见的变化、必要安装步骤和实际影响使用的限制。同一轮的小修改合并发布，不单独为图标或文案升版，也不把内部测试过程写成发行说明。

商店文案、权限理由和剩余发布步骤见 [扩展商店发布准备](扩展商店发布.md)。隐私政策源文件是 `docs/privacy.html`，需要单独公开托管后才能取得商店所需的政策 URL。
