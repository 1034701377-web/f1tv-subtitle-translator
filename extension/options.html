数据如何使用

API 密钥由本扩展保存在当前浏览器本地，不会上传给扩展开发者。翻译时，字幕文本会发送给你配置的翻译服务商；开启 TR 音轨识别或声音采集后，音频会发送给你配置的语音识别服务商。
